# English Exam - 2nd Grade

Examen interactivo de inglés para segundo grado de primaria, listo para GitHub Pages.

## Funciones
- 20 preguntas interactivas.
- Corrección inmediata por pregunta.
- Permite volver a intentar si el niño se equivoca.
- Puntaje final sobre 20 y porcentaje.
- Botón **Try again** para reiniciar.
- Botones **🔊 Listen** para escuchar las preguntas en inglés.
- El audio usa la voz del navegador mediante `SpeechSynthesis`, por lo que no requiere archivos MP3 ni librerías externas.
- Diseño adaptable a computadora, tablet y celular.

## Temas
- My House: bedroom, kitchen, bathroom, living room
- Prepositions of place: in, on, under
- Where's...? / Where are...?
- It's... / They're...
- Clothes: shirt, shoes, pants, dress
- Colors
- His / Her

## Publicarlo en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Descomprime este ZIP.
3. Sube `index.html` y `README.md` a la raíz del repositorio.
4. En GitHub, entra a **Settings > Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/ (root)`.
7. Guarda.
8. GitHub mostrará la dirección pública del examen.

## Sobre el audio
El niño debe presionar el botón **Listen** para reproducir el audio. Los navegadores modernos permiten este tipo de audio después de una interacción del usuario. La voz exacta puede variar según el dispositivo y el navegador.
